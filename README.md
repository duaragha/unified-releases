# Unified releases

Public installers and the SideStore update feed for Unified.

## SideStore source

Add this source once in SideStore. New Unified iOS builds will then appear in **My Apps** as
normal updates without manually downloading an IPA:

`https://raw.githubusercontent.com/duaragha/unified-releases/main/sidestore-source.json`

One-tap source link:

`sidestore://source?url=https%3A%2F%2Fraw.githubusercontent.com%2Fduaragha%2Funified-releases%2Fmain%2Fsidestore-source.json`

The latest source entry must be updated as part of every coordinated Windows, Linux, iOS, and
Android release.
